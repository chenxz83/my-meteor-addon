# 水晶光环+ (Crystal Aura Plus)

基于 Meteor Client 的 Minecraft Fabric 附加模组（Addon）。对 Meteor Client 自带的水晶光环（Crystal Aura）进行增强。

## 版本

| 目录 | Minecraft | Meteor Client |
|------|-----------|---------------|
| `crystal-aura-plus/` | 1.21.11 | 1.21.11 |
| `crystal-aura-plus-1.21.8/` | 1.21.8 | 1.21.8 |

## 包含内容

### 模块

- **水晶光环+（Crystal Aura Plus）** — 增强版水晶光环：单目标模式、目标优先级、忽略好友、自动放置黑曜石、忽略自伤、狂暴模式、手动激活键、反蹲坑、智能放置、爆图腾暂停、击杀/爆图腾提示等。
- **Crystal ESP** — 末地水晶穿墙高亮。
- **Kill Msg** — 击杀播报，自定义消息（支持 StarScript）。
- **AutoSign+** — 自动告示牌，自定义文本（支持 StarScript，可显示日期与时间）。

### HUD

- **水晶光环+ 状态** — 显示水晶数量、当前目标与击杀/爆图腾统计。

## 构建

```bash
./gradlew build
# 产物位于 build/libs/
```
